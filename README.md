## 📋 Sobre nosotros

**HIGH RP** es un servidor de roleplay para Multi Theft Auto: San Andreas. Acá vas a encontrar los repositorios con el código, resources, paneles web y herramientas que usamos para el desarrollo y administración del servidor.

## 🛠️ Tecnologías

- **Lua** — Scripts y resources de MTA:SA
- **HTML / CSS / JS** — Paneles web y herramientas
- **Python** — Bots y utilidades
